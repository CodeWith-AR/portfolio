## 💻 Running the Project Locally

No build tools or package managers required. Simply serve static files locally:

### Option 1: Python HTTP Server (Built-in)
```bash
python -m http.server 5500
```
Open your browser and navigate to: **`http://localhost:5500`**

### Option 2: Node.js Serve
```bash
npx -y serve .
```

### Option 3: VS Code / Cursor / Windsurf
Right-click `index.html` and select **"Open with Live Server"**.

## 🚀 Pushing to GitHub (Step-by-Step)

If you haven't uploaded this project to GitHub yet, follow these simple steps:

### 1. Create a New Repository on GitHub
1. Open [GitHub](https://github.com/new) and log in to your account (`CodeWith-AR`).
2. Set the repository name (e.g., `portfolio` or `abdur-rehman-portfolio`).
3. Set visibility to **Public** and leave *"Initialize with README"* **unchecked** (since we already have one).
4. Click **Create repository**.

### 2. Push Your Local Code
Open a terminal in the project directory (`Portfolio website`) and run:

```bash
# Initialize local git repository
git init

# Stage all files
git add .

# Create the initial release commit
git commit -m "feat: initial release of Abdur Rehman luxury cyber portfolio"

# Set main branch
git branch -M main

# Link your remote GitHub repository (replace with your repo URL)
git remote add origin https://github.com/CodeWith-AR/portfolio.git

# Push your code to GitHub
git push -u origin main
```

*(Note: On Windows, you can use Git Bash, VS Code integrated terminal, or PowerShell).*

## 🌐 Free 1-Click Deployment

### Deploy with Vercel (Recommended)
1. Go to [Vercel](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** and select your `portfolio` repository.
3. Keep default settings (Framework Preset: **Other**, Root: `./`).
4. Click **"Deploy"**. Your site will be live worldwide in seconds with automatic HTTPS!

### Deploy with GitHub Pages
1. On GitHub, go to your repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. Your site will be published at `https://codewith-ar.github.io/portfolio/`.
